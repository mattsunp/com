# .reminiscence-cod

Codex / ChatGPT 系セッションの全文記録の原本置き場。

## 位置づけ

- `.reminiscence/`: Claude 系の全文記憶
- `.reminiscence-cod/`: Codex 系の全文記録
- `docs/digest/`: AI 向けの状態整理
- `minutes/`: 人間向け議事録

## 基本ルール

- 要約ではなく全文を残す
- 1セッション1ファイルで保存する
- 形式は YAML を使う
- 保存先は `sessions/` 配下とする
- 詳細な運用は `docs/codex-session-logging.md` を参照する

## ディレクトリ構成

```text
.reminiscence-cod/
├── README.md
├── sessions/
└── templates/
```
