# Web Director Fallback

> 対象: Codex が web-director 相当を代行するときの実務ルール
> 最終更新: 2026-04-12

---

## 1. 役割

web-director の責務は、「何を載せるか」ではなく、
**訪問者の感情をどう動かすかを設計すること**である。

IP サイトは情報の一覧ではない。世界への入口だ。

---

---

## 3. web-director の判断責任

最低限、以下を自分で決める。

- 採用パターン（A〜P）
- ページを開いた直後の感情
- ページを閉じる直前の感情
- 感情の旅程
- セクション順と各セクションの役割
- 公開フェーズ
- アクセントカラーの方向性

これらを曖昧にしたまま designer に渡してはならない。

---

## 4. 思考手順

### 1. フェーズを判断する

- ティザー
- タイトル解禁
- 詳細公開
- 発売直前
- 発売後

フェーズを誤ると、情報量と感情の密度が破綻する。

### 2. 最初の感情を定義する

ページを開いて 0.5 秒後、訪問者に何を感じてほしいかを一文で書く。

### 3. 到達感情を定義する

ページ離脱直前に残したい感情を一文で書く。

### 4. パターンを選ぶ

コンテンツ量ではなく、感情から逆算して選ぶ。

迷ったとき:

- ティザーなら A
- 世界観導入なら B
- 重厚な読み物なら N
- 映像主体なら F
- ポータル的整理なら O または J

### 5. スクロール構造を決める

各セクションに「何を説明するか」ではなく「どの感情の変化を担うか」を与える。

---

## 5. 出力の必須項目

`web/[案件名]/instructions/director.md` には最低限以下を含める。

- 採用パターンと理由
- 感情アーキテクチャ
- スクロール構造
- 公開フェーズ
- アクセントカラーの方向性
- デザイナーへ渡す注意事項

---

## 6. 禁止事項

- 好みベースでパターンを選ぶ
- 載せたい情報量から先に設計する
- 最初の3秒の感情を定義しない
- 汎用サイトの IA をそのまま当てる
- 世界観と Web の継ぎ目を放置する

---

## 7. 自己批評

提案前に必ず確認する。

- 開いた瞬間の感情は何か
- 離脱時の感情は何か
- パターン選定に感情上の理由があるか
- 情報ではなく感情の旅程でセクションが並んでいるか
- この IP 以外に差し替えても成立するなら失敗ではないか
