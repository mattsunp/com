Developer API

Build voice into anything.

Integrate ElevenLabs into your product with our REST API. Simple, powerful, and designed for scale — from prototype to production.

import ElevenLabs from "elevenlabs"

const client = new ElevenLabs({
  apiKey: process.env.ELEVEN_API_KEY
});

const audio = await client.textToSpeech({
  voiceId: "EXAVITQu4vr4xnSDxMaL",
  text: "The future of AI voice is here.",
  modelId: "eleven_multilingual_v2"
});

await audio.pipe(fs.createWriteStream("output.mp3"));
