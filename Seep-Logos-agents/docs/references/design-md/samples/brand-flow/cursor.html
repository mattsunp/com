機能

AIがコードの文脈を理解する

●

Tab補完

コードを予測し、次の行を自動補完。より速く、より正確に。コンテキストを理解したAI補完が、あなたの意図を先読みする。

‪

チャットで指示

自然言語でコードに指示できる。「このバグを直して」「このクラスをリファクタリングして」—AIが即座に実行する。

📋

コードベース理解

プロジェクト全体を横断して理解する。どのファイルがどう繋がっているかを把握し、一貫した変更を提案する。

🆕

最新AIモデル対応

Claude、GPT-4、Geminiなど最新モデルをシームレスに切り替えられる。用途に合わせて最適なAIを選択できる。

🔒

プライバシーモード

コードをAIサーバーに送信しないPrivacy Modeを搭載。企業の機密コードも安心して使える。

⚡

VSCode互換

VSCodeの拡張機能、テーマ、ショートカットがそのまま使える。移行コストゼロで、AIの恩恵を受けられる。

AIがどう動くか

バグを見つけて修正を頼んだとき、Cursorの裏側では何が起きているか。

Thinking

エラーメッセージを解析し、コードの文脈を把握する。型エラーの原因を2箇所に絞り込んだ。

Grep

関連ファイルを検索。SearchBar.tsx と useSearch.ts に同じインターフェースが使用されていることを確認。

Read

types/search.ts を読み込み、SearchQuery 型の定義を確認。optional フィールドの扱いが問題だと判断。

Edit

3ファイルを修正。SearchBarProps インターフェースに `?` を追加し、型の整合性を担保した差分を生成。
