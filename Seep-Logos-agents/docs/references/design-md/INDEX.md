## 使い方

### web-designer エージェントへの渡し方

```
このプロジェクトのWebサイトを設計してください。
参考にするデザインの雰囲気: ABEMAのダーク没入感 + MUJIのミニマルな余白感
詳細は以下のDESIGN.mdを参照:
- docs/references/design-md/japan/abema_DESIGN.md
- docs/references/design-md/japan/muji_DESIGN.md
```

### Seep Logos ゲーム・アニメ系おすすめ参考先

| 用途 | 推奨参照 |
|------|---------|
| ダーク・没入感UI | ABEMA（黒背景、グリーン+ピンクアクセント） |
| クリエイター向け | pixiv（ギャラリー型、ブルーアクセント） |
| インパクト重視LP | Novasell（超巨大タイポ、ネオングリーン） |
| ミニマルブランドサイト | MUJI（きなり色、line-height 1.6） |
| 技術文書・Wiki | Zenn（ブルー、line-height 1.8） |
