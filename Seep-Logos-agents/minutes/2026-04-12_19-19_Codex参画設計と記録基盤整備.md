### 1. Seep Logos への Codex 参画方針
- 依頼内容：
  `Seep-Logos-agents` を一つの企業体として Claude Code で運用している前提で、Codex も自然に参画できる形を整えたい。
- 対応エージェント：
  Codex
- 主な出力・決定事項：
  リポジトリ構成、`CLAUDE.md`、`docs/digest/_system-state.md`、`docs/_index.md`、`docs/output-format.md` を確認し、このプロジェクトが「会社OS」に近い運用基盤であることを整理した。
  Codex は司令塔の代替ではなく、共通憲章を守りながら実務を担う協働メンバーとして参画する方針を採用した。
- 次のアクション：
  Codex と Claude Code の役割分担を文書として残す。

### 2. `CLAUDE.md` の位置づけ整理
- 依頼内容：
  `Claude Code` における `CLAUDE.md` や memory のようなものが Codex にもあるのか、また `CLAUDE.md` を共通ルールとして扱えるかを整理したい。
- 対応エージェント：
  Codex
- 主な出力・決定事項：
  Codex 側には `~/.codex/` 配下に状態やログの永続データはあるが、プロジェクトごとの共通憲章ファイルとしては `CLAUDE.md` を使うのが最も自然と判断した。
  `CLAUDE.md` を Seep Logos に参画する全 AI・全担当の共通憲章として扱う方針を採用し、冒頭にその旨を明記した。
- 次のアクション：
  下位文書として Codex 向けの参画ルールを `docs/` に整備する。

### 3. Codex と Claude Code の handoff 設計
- 依頼内容：
  Claude Code の使用制限・overloaded 時や、逆に Codex から Claude Code へ戻すときに、並行運用しやすい handoff 設計を作りたい。
- 対応エージェント：
  Codex
- 主な出力・決定事項：
  AI 間の継続性は内部記憶共有ではなく、共有記録と handoff の品質で担保する方針を採用した。
  `docs/codex-collaboration.md` を新規作成し、Codex の主担当領域、Claude Code 主導領域、共有記録への着地ルール、代行運用の原則を整理した。
  `docs/handoff-protocol.md` を新規作成し、最小 handoff テンプレートと `Claude Code → Codex`、`Codex → Claude Code` の返却要件を定義した。
  `docs/handoff-samples.md` を新規作成し、実例ベースの手本を追加した。
- 次のアクション：
  実案件で handoff サンプルを一度本番利用し、粒度を調整する。

### 4. Codex セッションの全文保全方針
- 依頼内容：
  `.reminiscence` を Claude と Codex で直接共有しなくてもよいが、Codex との会話も要約ではなく全文のまま保存したい。
- 対応エージェント：
  Codex
- 主な出力・決定事項：
  Codex 系の全文記録は `.reminiscence-cod/` に別系統で保持する方針を採用した。
  正本形式は JSONL ではなく YAML とし、1セッション1ファイルでメタ情報、会話全文、成果物、handoff を同居させる設計を採用した。
  `docs/codex-session-logging.md` を新規作成し、命名規則、必須項目、messages / artifacts / handoff のルールを定義した。
  `.reminiscence-cod/README.md`、`.reminiscence-cod/templates/session-template.yaml`、`.reminiscence-cod/sessions/.gitkeep` を追加した。
  `docs/_index.md` には、Codex 向け文書と `.reminiscence-cod/` の位置づけが分かる導線を追加した。
- 次のアクション：
  実際の1セッション分を `.reminiscence-cod/sessions/` に本番形式で保存し、運用粒度を確認する。

## 決定事項まとめ
- `CLAUDE.md` は Claude Code 専用設定ではなく、Seep Logos に参画する全 AI・全担当の共通憲章として扱う。
- Codex は司令塔の代替ではなく、共通憲章を守りながら実務を担う協働メンバーとして参画する。
- AI 間の継続性は、モデル固有の内部記憶共有ではなく、共有記録と handoff によって担保する。
- Codex と Claude Code の handoff は `docs/handoff-protocol.md` に従う。
- Codex 系セッションの全文記録は `.reminiscence-cod/` に YAML で 1セッション1ファイル保存する。
