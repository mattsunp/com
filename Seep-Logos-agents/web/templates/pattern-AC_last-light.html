— epilogue —

それでも、光は残っていた

世界の終わりに近いほど、残されたものの輝きが増す。これはその記録だ。

// Chapter I

まだ、誰もが戻れると信じていた

日が落ちると、彼女は必ず同じ場所に立った。地平線が橙に染まる、あの瞬間だけは、何も変わっていないように見えた。

世界が壊れていることを知っていた。それでも人は、沈む太陽に向かって手を伸ばした。記憶とは、そういうものだ。

// Chapter II

そして、ほとんどのものが去った

名前が、一つずつ消えていった。声が、足音が、笑い声が。それでも世界は回り続けた。あたかも、何事もなかったかのように。

残された者は、消えたものの重さを背負って歩いた。それが生きるということだった。

// Chapter III

最後の夜は、静かだった

風もなく、音もなく、ただ暗さだけがあった。それでも、一つだけ光が残っていた。小さく、揺れながら、それでも確かに。

消えないために戦ったのではない。ただ、そこにあり続けた。それで十分だった。

終わりではない。
次の始まりを待つ、沈黙だ。
